# CONFIGURAÇÃO RÁPIDA

Abra `config.js`.

Você encontrará:

window.SUPABASE_URL = "https://SEU-PROJETO.supabase.co";
window.SUPABASE_ANON_KEY = "COLE_SUA_ANON_KEY_AQUI";

Depois que criar seu projeto no Supabase:
1. Coloque a URL do projeto na primeira linha.
2. Cole a chave **anon public** na segunda linha.
3. Não use a `service_role key`.

Todo o JavaScript do Study Order já está incluído em `app.js`.
O Supabase JS também já é carregado pelo `index.html`.
